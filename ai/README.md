# AI Module

This folder contains the artificial intelligence and computer vision
components of Smart Recycle AI-Hub.

## V1 AI Goal

The AI system will detect and classify four recyclable waste categories:

- Plastic
- Metal
- Glass
- Paper / Cardboard

Unsupported or uncertain objects will be handled as Reject by the
decision logic.

## Planned AI Stack

- Python
- Ultralytics
- YOLO26
- OpenCV

## Planned Components

This folder will later contain:

- Model training code
- Image and camera inference code
- Evaluation tools
- Decision logic
- Model configuration
